# Site Portfólio

## Descrição
Este projeto consiste em um site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript. O objetivo é apresentar minhas habilidades, formação acadêmica e interesses na área de tecnologia, com foco em programação e raciocínio lógico.

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Página inicial com apresentação pessoal
- Seção sobre mim
- Exibição de habilidades
- Informações de contato
